# AnatoMove — тренер, который видит твои мышцы

Веб-приложение для кейса **«Motion. Камера вместо джойстика»** (Admit Hackathon 2026).
Направление — **фитнес-тренер**.

**Демо:** https://nurtas-07.github.io/AnatoMove/ ← вставить ссылку после деплоя
**Команда:** НАЗВАНИЕ КОМАНДЫ

Человек открывает ссылку, встаёт перед камерой и тренируется. Всё управление — движениями тела. Приложение считает повторы, подсвечивает работающие мышцы прямо на теле человека, как в анатомическом атласе, и, если техника нарушена, говорит, что именно не так и как это исправить.

## Как пользоваться

1. Открой ссылку в Chrome, Edge или Safari и нажми «Включить камеру». Это единственный клик: браузер требует его, чтобы дать доступ к камере и звуку.
2. Поставь ноутбук или телефон на уровне пояса и отойди на 2–3 метра, чтобы камера видела тебя от головы до стоп.
3. Дальше всё жестами:
   - подними **правую руку** над головой и подержи секунду — «Начать тренировку»;
   - подними **левую руку** — «Мой прогресс»;
   - во время упражнения подними **обе руки высоко** над головой на 2 секунды — пропустить упражнение.
4. Тренировка — три упражнения подряд, затем итоги: баллы, процент чистой техники, главная ошибка в каждом упражнении и карта нагруженных мышц.

Для жюри есть запасной вариант: пункты меню можно нажать и мышью.

## Движения и действия

| Движение | Что происходит | Как распознаётся |
|---|---|---|
| Правая рука над головой, 1 с | выбор пункта справа: «Начать», «Ещё раз», «Назад» | запястье выше носа |
| Левая рука над головой, 1 с | выбор пункта слева: «Мой прогресс», «В меню» | запястье выше носа |
| Обе руки высоко над головой, 2 с | пропуск упражнения | оба запястья выше носа с запасом в 0,8 ширины плеч, чтобы не срабатывало при разведении рук |
| Приседание | повтор в упражнении «Приседания» | длина бедра в кадре относительно длины стоя |
| Разведение рук в стороны | повтор в упражнении «Разведение рук» | угол «корпус — плечо — локоть» |
| Подъём колена | повтор в «Подъёме коленей», каждая нога считается отдельно | насколько колено поднялось к линии таза |

## Режим «ошибка»

Приложение не отвечает «не распознано». Каждую ошибку оно называет и сразу говорит, как её исправить:

- на экране появляется жёлтая карточка «Поправка»: что не так и как исправить;
- голос произносит короткую подсказку: человек далеко от экрана и не всегда на него смотрит;
- на суставах, где ошибка, пульсируют жёлтые кольца;
- если из-за ошибки нагрузка уходит не в ту мышцу, эта мышца подсвечивается жёлтым. Например, при подъёме рук выше плеч загорается трапециевидная мышца вместо дельтовидной.

Повтор с ошибкой засчитывается, но не считается «чистым». В итогах для каждого упражнения показана самая частая ошибка и совет, а на карте мышц — какие мышцы получили лишнюю нагрузку.

Ошибка засчитывается, только если признак держится 4 кадра подряд: так случайное дрожание точек не даёт ложных срабатываний.

| Упражнение | Ошибка | Как определяем | Подсказка |
|---|---|---|---|
| Приседания | колени заваливаются внутрь | в нижней точке расстояние между коленями меньше 80% расстояния между стопами | «Разводи колени наружу — по линии носков» |
| | сильный наклон корпуса | корпус по вертикали стал короче, чем стоя: наклон больше 50° | «Держи грудь выше и спину ровно, таз уводи назад» |
| | вес на одной ноге | таз смещён от центра стоп больше чем на 35% ширины таза | «Распредели вес поровну на обе стопы» (с указанием стороны) |
| | неглубокий присед | бедро укоротилось меньше чем до 45% длины стоя | «Опускайся ниже — бёдра почти параллельно полу» |
| Разведение рук | руки выше плеч | угол отведения больше 110° | «Поднимай только до горизонтали — выше работает уже трапеция» |
| | руки не дошли до плеч | средний пик меньше 75° | «Поднимай руки выше — до линии плеч» |
| | согнуты локти | угол в локте меньше 140° | «Держи руки почти прямыми» |
| | одна рука отстаёт | разница между руками больше 20° | «Левая/правая рука отстаёт — поднимай обе одновременно» |
| | плечи к ушам | расстояние «плечи — уши» уменьшилось до 72% от исходного | «Опусти плечи вниз и назад» |
| Подъём коленей | колено низко | бедро поднялось меньше чем на 60% до линии таза | «Поднимай колено до уровня таза» (с указанием стороны) |
| | корпус качается вбок | отклонение линии «таз — плечи» от вертикали больше 12° | «Держи спину ровно и напряги пресс» |
| | не чередует ноги | одна нога три раза подряд | «Чередуй ноги — сейчас очередь правой/левой» |

Отдельно есть подсказки о положении перед камерой: «Не видно колен и стоп — отойди на шаг назад», «Ты стоишь боком — повернись к камере лицом», «Стопы стоят вплотную — поставь на ширину плеч» и другие. Подготовительный отсчёт перед упражнением идёт, только пока человек правильно стоит в кадре.

## Анатомия

Во время упражнения работающие мышцы рисуются на теле человека веретёнами с волокнами, яркость зависит от фазы движения. Две главные мышцы подписаны выносными линиями, как в атласе: латинское название и русское. Перед каждым упражнением показан список мышц, которые будут работать, и они подсвечиваются на теле. В итогах — карта мышц спереди и сзади с нагрузкой за тренировку.

Мышцы: четырёхглавая мышца бедра, большая ягодичная, приводящие мышцы бедра, мышца, выпрямляющая позвоночник, дельтовидная, трапециевидная, подвздошно-поясничная, прямая мышца живота.

## Как это работает

1. **MediaPipe Pose Landmarker** находит 33 точки тела в каждом кадре прямо в браузере. Видео никуда не отправляется.
2. **Собственная логика** (`js/exercises.js`) превращает точки в метрики, по ним ведёт конечный автомат повтора (стою → опускаюсь → встал) и проверяет правила техники.
3. Метрики подобраны так, чтобы не зависеть от роста человека и расстояния до камеры. Например, глубина приседа — это отношение текущей длины бедра в кадре к длине бедра стоя. Эталон «стоя» запоминается сам и плавно подстраивается, если человек подошёл или отошёл.
4. Все пороги собраны в одном объекте `CONFIG` в начале `js/exercises.js`.

## Запуск локально

Нужен любой локальный веб-сервер: ES-модули не работают при открытии файла напрямую (`file://`).

```bash
git clone https://github.com/ИМЯ-ПОЛЬЗОВАТЕЛЯ/anatomove.git
cd anatomove
python3 -m http.server 8000
```

Открыть http://localhost:8000. На `localhost` камера работает без https. Нужен интернет: библиотека MediaPipe грузится с jsDelivr, модель — с Google Storage.

Параметры адреса:
- `?debug` — живые значения метрик (углы, глубина) для настройки порогов;
- `?model=lite` — облегчённая модель для слабых компьютеров. На телефоне она включается сама.

## Деплой на GitHub Pages

Settings → Pages → Source: *Deploy from a branch* → ветка `main`, папка `/ (root)` → Save. Через 1–2 минуты сайт откроется по адресу `https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/anatomove/`. GitHub Pages работает по https — это обязательно для доступа к камере.

## Тесты

Логика упражнений проверяется на синтетических позах: сгенерированный «человек» из 33 точек приседает, поднимает руки и колени, правильно и с ошибками.

```bash
node tests/exercises.test.mjs
```

17 проверок: подсчёт чистых повторов и распознавание каждой ошибки, включая сторону тела.

## Структура

```
index.html          экраны приложения
css/style.css       оформление, адаптация под телефон
js/main.js          сценарий: экраны, жесты, цикл распознавания, итоги, прогресс
js/exercises.js     правила упражнений и режима «ошибка» (без DOM)
js/geometry.js      геометрия: углы, сглаживание, эталоны
js/anatomy.js       мышцы на теле, подписи-атлас, карта мышц в итогах
js/pose.js          камера и модель MediaPipe (GPU, при ошибке — CPU)
js/voice.js         голосовые подсказки и звуковые сигналы
tests/              тесты логики в Node
```

## Технологии

JavaScript (ES-модули) без сборки и фреймворков, Canvas 2D, SVG, Web Speech API, Web Audio API, localStorage. Распознавание позы — [MediaPipe Tasks Vision](https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker) (Apache 2.0). Шрифты — Cormorant Garamond и Onest (Google Fonts, OFL).

## Бонусы кейса

- **Собственная логика распознавания:** все упражнения и ошибки — наши правила поверх точек MediaPipe, без готовых «счётчиков».
- **Прогресс:** история тренировок в браузере, лучший результат, график техники по последним тренировкам.
- **Телефон:** фронтальная камера, облегчённая модель, раскладка для вертикального экрана.
- **Звук и визуальные эффекты:** голосовые подсказки и счёт, звуковые сигналы, подсветка мышц на теле.
