# AnatoMove — тренер, который видит твои мышцы

Веб-приложение для кейса **«Motion. Камера вместо джойстика»** (Admit Hackathon 2026).
Направление — **фитнес-тренер**.

**Демо:** https://nurtas-07.github.io/AnatoMove
**Команда:** GidraGo

Человек открывает ссылку, встаёт перед камерой и тренируется. Всё управление — движениями тела. Приложение считает повторы, подсвечивает работающие мышцы прямо на теле, как в анатомическом атласе, и, если техника нарушена, говорит, что именно не так и как это исправить. В итогах — стоп-кадры ошибок и карта нагрузки на мышцы.

## Как пользоваться

1. Открой ссылку в Chrome, Edge или Safari и нажми «Включить камеру». Это единственный клик: браузер требует его, чтобы дать доступ к камере и звуку.
2. Поставь ноутбук или телефон на уровне пояса и отойди на 2–3 метра, чтобы камера видела тебя от головы до стоп.
3. Дальше всё жестами:
   - **правая рука** над головой, 1 секунда — «Полная тренировка» (6 упражнений подряд);
   - **левая рука** — «Выбрать упражнение»: в каталоге левая рука листает, правая запускает;
   - **обе руки** над головой — «Мой прогресс» или «Назад в меню»;
   - во время упражнения **скрести руки на груди** на 2 секунды — пропустить упражнение.
4. После тренировки — итоги: баллы, процент чистой техники, лучшая серия, главная ошибка и совет по каждому упражнению, карта мышц и стоп-кадры ошибок.

Для жюри есть запасной вариант: все пункты меню можно нажать и мышью.

## Движения и действия

| Движение | Что происходит | Как распознаётся |
|---|---|---|
| Правая рука над головой, 1 с | пункт справа: «Полная тренировка», «Начать», «Ещё раз» | запястье выше носа |
| Левая рука над головой, 1 с | пункт слева: «Выбрать упражнение», «Листать», «В меню» | запястье выше носа |
| Обе руки над головой, 1,3 с | пункт по центру: «Мой прогресс», «Назад в меню» | оба запястья выше носа |
| Руки скрещены на груди, 2 с | пропуск упражнения | левое запястье ушло за правое на уровне корпуса. Такой позы нет ни в одном упражнении, а посреди повтора жест не копится |
| Приседание | повтор в «Приседаниях» | длина бедра в кадре относительно длины стоя |
| Разведение рук в стороны | повтор в «Разведении рук» | угол «корпус — плечо — локоть» |
| Подъём колена | повтор в «Подъёме коленей», каждая нога считается отдельно | насколько колено поднялось к линии таза |
| Жим руками вверх | повтор в «Жиме» | высота кистей над плечами в долях длины руки и угол в локте |
| Боковой наклон | повтор в «Наклонах», каждая сторона отдельно | наклон линии «таз — плечи» от вертикали |
| Прыжок «звёздочка» | повтор в «Звёздочке» | угол подъёма рук и ширина стоп относительно ширины плеч |

## Режим «ошибка»

Приложение не отвечает «не распознано». Каждую ошибку оно называет и сразу говорит, как её исправить:

- на экране появляется жёлтая карточка «Поправка»: что не так и как исправить;
- голос произносит короткую подсказку: человек стоит далеко от экрана и не всегда на него смотрит;
- на суставах, где ошибка, пульсируют жёлтые кольца;
- если из-за ошибки нагрузка уходит не в ту мышцу, эта мышца подсвечивается жёлтым. Например, при подъёме рук выше плеч вместо дельтовидной загорается трапециевидная;
- момент ошибки сохраняется **стоп-кадром**: берётся кадр из пика движения за последние 1,6 с, с подсветкой мышц и кольцами на проблемных суставах. В итогах стоп-кадры показаны с подписью «что не так и как исправить». Кадры живут только в памяти страницы и никуда не отправляются.

Повтор с ошибкой засчитывается, но не считается «чистым» и обрывает серию чистых повторов. В итогах для каждого упражнения показана самая частая ошибка с советом, а на карте мышц — какие мышцы получили лишнюю нагрузку и почему.

Ошибки, которые видны в движении, засчитываются, только если признак держится 4 кадра подряд: так случайное дрожание точек не даёт ложных срабатываний.

| Упражнение | Ошибка | Как определяем | Подсказка |
|---|---|---|---|
| Приседания | колени заваливаются внутрь | в нижней точке расстояние между коленями меньше 80% расстояния между стопами | «Разводи колени наружу — по линии носков» |
| | сильный наклон корпуса | корпус по вертикали стал короче, чем стоя: наклон больше 50° | «Держи грудь выше и спину ровно, таз уводи назад» |
| | вес на одной ноге | таз смещён от центра стоп больше чем на 35% ширины таза | «Распредели вес поровну на обе стопы» (с указанием стороны) |
| | неглубокий присед | бедро укоротилось меньше чем до 45% длины стоя | «Опускайся ниже — бёдра почти параллельно полу» |
| | слишком быстро | повтор быстрее 0,9 с | «Медленнее: 2 секунды вниз, 1 — вверх» |
| Разведение рук | руки выше плеч | угол отведения больше 110° | «Поднимай только до горизонтали — выше работает уже трапеция» |
| | руки не дошли до плеч | средний пик меньше 75° | «Поднимай руки выше — до линии плеч» |
| | согнуты локти | угол в локте меньше 140° | «Держи руки почти прямыми» |
| | одна рука отстаёт | разница между руками больше 20° | «Поднимай обе руки одновременно» (с указанием стороны) |
| | плечи к ушам | расстояние «плечи — уши» уменьшилось до 72% от исходного | «Опусти плечи вниз и назад» |
| | слишком быстро | повтор быстрее 1 с | «Медленнее: пусть работают мышцы, а не инерция» |
| Подъём коленей | колено низко | бедро поднялось меньше чем на 60% до линии таза | «Поднимай колено до уровня таза» (с указанием стороны) |
| | корпус качается вбок | отклонение линии «таз — плечи» от вертикали больше 12° | «Держи спину ровно и напряги пресс» |
| | не чередует ноги | одна нога три раза подряд | «Чередуй ноги — сейчас очередь правой/левой» |
| Жим руками вверх | руки не выпрямлены | в верхней точке угол в локте меньше 150° | «В верхней точке полностью выпрями локти» |
| | одна рука отстаёт | разница в высоте кистей больше 18% длины руки | «Выжимай обе руки одновременно» (с указанием стороны) |
| | плечи к ушам | как в разведении рук | «Держи плечи опущенными — жми руками, а не шеей» |
| | слишком быстро | повтор быстрее 0,9 с | «Медленнее» |
| Боковые наклоны | слабый наклон | пик меньше 18° | «Наклоняйся глубже — ладонь скользит по бедру почти до колена» (с указанием стороны) |
| | корпус уходит вперёд | корпус в кадре стал короче 82% от длины стоя: боковой наклон длину не меняет, а наклон вперёд укорачивает | «Наклоняйся строго в сторону — будто стоишь между двумя стёклами» |
| | таз уезжает в сторону | таз сместился от центра стоп больше чем на половину ширины таза | «Держи таз над стопами — наклон только в пояснице» |
| | не чередует стороны | три наклона подряд в одну сторону | «Чередуй стороны» |
| Прыжки «звёздочка» | руки не до верха | угол подъёма рук меньше 140° | «Поднимай руки через стороны до конца — кисти над головой» |
| | ноги узко | стопы разошлись меньше чем на 1,5 ширины плеч | «В прыжке ставь стопы шире плеч» |

Отдельно есть подсказки о положении перед камерой: «Не видно колен и стоп — отойди на шаг назад», «Ты стоишь боком — повернись к камере лицом», «Стопы стоят вплотную — поставь на ширину плеч» и другие. Подготовительный отсчёт перед упражнением идёт, только пока человек правильно стоит в кадре.

## Анатомия

Во время упражнения работающие мышцы рисуются на теле человека веретёнами с волокнами, яркость зависит от фазы движения. Две главные мышцы подписаны выносными линиями, как в атласе: латинское название и русское. В боковых наклонах ярче подсвечивается сторона, противоположная наклону: именно её мышцы контролируют движение и возвращают корпус.

Перед каждым упражнением показан список мышц, которые будут работать, и они подсвечиваются на теле. Там же — факт «Знаешь ли ты?»: например, что волокна наружной косой мышцы живота идут так же, как пальцы рук, засунутых в карманы куртки. В итогах — карта мышц спереди и сзади с нагрузкой за тренировку.

13 мышц: четырёхглавая мышца бедра, большая и средняя ягодичные, приводящие мышцы бедра, мышца, выпрямляющая позвоночник, квадратная мышца поясницы, дельтовидная, трапециевидная, трёхглавая мышца плеча, подвздошно-поясничная, прямая и наружная косая мышцы живота, икроножная.

## Баллы и прогресс

Баллы: 10 за чистый повтор, 4 за повтор с ошибкой, плюс 3 за каждый повтор лучшей серии чистых повторов. С пятого чистого повтора подряд голос отмечает серию.

История тренировок хранится в браузере: лучший результат, последние тренировки и график техники.

## Как это работает

1. **MediaPipe Pose Landmarker** находит 33 точки тела в каждом кадре прямо в браузере. Видео никуда не отправляется.
2. **Собственная логика** (`js/exercises.js`) превращает точки в метрики, по ним ведёт конечный автомат повтора (исходное положение → движение → возврат) и проверяет правила техники.
3. Метрики подобраны так, чтобы не зависеть от роста человека и расстояния до камеры. Например, глубина приседа — это отношение текущей длины бедра в кадре к длине бедра стоя. Эталон «стоя» запоминается сам и плавно подстраивается, если человек подошёл или отошёл.
4. Все пороги собраны в одном объекте `CONFIG` в начале `js/exercises.js`.

Надёжность: если основная версия MediaPipe не загрузится с CDN, берётся запасная. Модель запускается на видеокарте, при ошибке — на процессоре, а если не запустится точная модель — лёгкая. Если в системе нет русского голоса, голосовые подсказки выключаются, остаются сигналы и текст. Жесты рассчитаны по реальному времени, поэтому удержание длится честную секунду и на слабом устройстве.

## Запуск локально

Нужен любой локальный веб-сервер: ES-модули не работают при открытии файла напрямую (`file://`).

```bash
git clone https://github.com/nurtas-07/AnatoMove.git
cd AnatoMove
python3 -m http.server 8000
```

Открыть http://localhost:8000. На `localhost` камера работает без https. Нужен интернет: библиотека MediaPipe грузится с jsDelivr, модель — с Google Storage.

Параметры адреса:
- `?debug` — живые значения метрик (углы, глубина) для настройки порогов;
- `?model=lite` — облегчённая модель для слабых компьютеров. На телефоне она включается сама.

## Деплой

GitHub Pages: Settings → Pages → Source: *Deploy from a branch* → ветка `main`, папка `/ (root)`. Сайт: https://nurtas-07.github.io/AnatoMove/ (https обязателен для доступа к камере).

## Тесты

Логика упражнений проверяется на синтетических позах: сгенерированный «человек» из 33 точек выполняет все шесть упражнений правильно и с ошибками.

```bash
node tests/exercises.test.mjs
```

31 проверка: подсчёт чистых повторов, распознавание каждой ошибки (включая сторону тела), темп, серия. Ещё одна проверка следит, чтобы посреди повтора не копился жест пропуска.

## Структура

```
index.html          экраны приложения
css/style.css       оформление, адаптация под телефон
js/main.js          сценарий: экраны, жесты, каталог, цикл распознавания, стоп-кадры, итоги, прогресс
js/exercises.js     правила шести упражнений и режима «ошибка» (без DOM)
js/geometry.js      геометрия: углы, сглаживание, эталоны
js/anatomy.js       мышцы на теле, подписи-атлас, карта мышц в итогах
js/pose.js          камера и модель MediaPipe с запасными вариантами
js/voice.js         голосовые подсказки и звуковые сигналы
tests/              тесты логики в Node
```

## Технологии

JavaScript (ES-модули) без сборки и фреймворков, Canvas 2D, SVG, Web Speech API, Web Audio API, localStorage. Распознавание позы — [MediaPipe Tasks Vision](https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker) (Apache 2.0). Шрифты — Cormorant Garamond и Onest (Google Fonts, OFL).

## Бонусы кейса

- **Собственная логика распознавания:** все упражнения, ошибки и жесты — наши правила поверх точек MediaPipe, без готовых «счётчиков».
- **Прогресс:** история тренировок, лучший результат, график техники, серии чистых повторов.
- **Телефон:** фронтальная камера, облегчённая модель, раскладка для вертикального экрана.
- **Звук и визуальные эффекты:** голосовые подсказки и счёт, звуковые сигналы, подсветка мышц на теле, стоп-кадры ошибок.
